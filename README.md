# Java CLI Number Guesser 🎲

A command-line interactive application built in core Java that challenges the user to guess a randomly generated number within a constrained number of attempts.

This project focuses on core Java logic, particularly handling standard input/output streams, implementing state-driven game loops, and enforcing strict input validation to prevent application crashes from unexpected user data.

### 🛠️ Tech Stack
* **Language:** Java (JDK)
* **Concepts:** `java.util.Scanner`, `java.util.Random`, `try-catch` exception handling

### 🧠 Core Learnings
* Managing application state and control flow using `while` and `do-while` loops.
* Securing the application against `InputMismatchException` through defensive programming.
